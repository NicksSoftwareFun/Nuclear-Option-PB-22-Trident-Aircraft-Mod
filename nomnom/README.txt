# NOMNOM manifest

`PB22Trident.json` is the manifest for listing this mod on [NOMNOM](https://github.com/KopterBuzz/NOMNOM). After publishing the release, copy the SHA-256 shown next to `PB22Trident.dll` on the release page into `hash` (and check `version` and `downloadUrl` match the tag), then add the file to `modManifests/` in a fork of NOMNOM and open a pull request to `main`.
